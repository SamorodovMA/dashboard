# 📦 Dashboard расписания доставки

Мониторинг синхронизации между AX ESHOP и сайтом.  
Визуализация расчёта плановых дат доставки (ПДД) с детализацией по этапам и группам доноров.

## Цель проекта

Предоставить пользователям (логистам, менеджерам) единый интерфейс для:

- Расчёта плановой даты доставки на основе параметров заказа
- Выбора оптимального склада-донора и способа доставки
- Просмотра детализации по этапам обработки заказа (Подбор → Перемещение → Упаковка → ПДО → ПДД)
- Выбора удобной даты и временного слота для доставки

## Функциональность

### Фильтры
- **Товар** — выбор артикула
- **Группа доноров** — Коптево, Сум, Браст, ДЛТ, Оксмер, Бутики
- **Склад комплектации** — КоптИнтмаг, ИнтМаг, ДИнтМаг
- **Тип доставки** — ССД / ПВЗ
- **Код способа** — выбор с описанием (город, тип доставки)
- **Тип карты клиента** — White, Orange, Black
- **Привилегия** — VIP_online, Orange+, Black и др.
- **Тестовая позиция** — расчёт по всем донорам

### Результаты
- **Плановая дата доставки (ПДД)** — календарь на 7 дней с выбором даты и временного слота
- **Детализация расчёта** — таблица этапов по каждому донору:
  - Подбор → Перемещение → Упаковка → ПДО → ПДД
  - Для ПДО и ПДД колонка "Конец" не отображается (прочерк)
- **Информационная панель** — выбранный склад, тип доставки, код способа

### Адаптивность
- Десктоп (≥900px) — полная версия
- Планшет (768–900px) — компактные фильтры
- Телефон (480–768px) — таблица в виде карточек
- Маленький телефон (≤480px) — всё в колонку

## Разработка

```bash
# Клонировать репозиторий
git clone https://github.com/SamorodovMA/dashboard.git

# Переключиться на ветку разработки
git checkout dev

# Открыть index.html в браузере
# Сборка не требуется — чистый HTML/CSS/JS
```

### Переключение на реальное API

В файле [`js/config.js`](js/config.js):

```js
APP.apiBaseUrl = 'https://axapta.company.ru';  // URL вашего API
APP.useMockData = false;                         // отключить мок-данные
```
